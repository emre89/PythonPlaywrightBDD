# User Stories

## US1: Catalog

As a user
I want to see a list of books
So that I can choose my favorites

## US2: Add new book

As a user
I want to add a new book to the catalog
So that it appears for me and others

## US3: Mark favorites

As a user
I should be able to add/remove books to/from my favorites list
So that I can update my favorite book list
